# First Post

### *A snail mail simulator for young people*

**A browser idle/strategy toy** about writing, stamping, and sending physical letters across the world, teaching the lost art of snail mail.

</div>

---

## What this is

You are a young pen pal learning the ropes of physical correspondence. Each tick, you draft letters, buy stamps, and drop them into mailboxes to reach friends across real postal networks. Upgrades include learning cursive, discovering better envelopes, and understanding postal routing.

Everything is flavour. There is no real target, no real network exploit, and no network call of any kind.

## Run it

- **Play in your browser:** <https://metadatastician.github.io/first-post/>
- **Play locally:** open `first-post.html` — self-contained, no server, no build step, nothing to install.

Any modern browser. No dependencies — nothing to install.
